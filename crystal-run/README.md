# Crystal Run

A tiny browser-playable 2D arcade prototype.

## Run
Open [index.html](./index.html) in a modern browser. No build tools or dependencies required.

## Goal
Collect 10 energy crystals while avoiding two moving drones. You have 3 lives.

## Controls
- Keyboard: WASD or arrow keys.
- Mobile: use the on-screen directional buttons.
- Restart: press the Restart button.

## Prototype scope
- Single-screen canvas arena.
- Four-direction movement.
- Random crystal placement.
- Moving hazards and collision damage.
- Win/lose states and restart.

This is an early gameplay test, not a finished game.
